# 0024 · 输入条底角圆角 —— 贴底基础上底角改圆角并留空隙

## 状态

已验证(2026-08-17;纯 CSS 改动,静态验证,视觉效果待重启窗口确认)

## 日期

2026-08-17

## 目的

0023 把输入条改成通栏贴窗底后,底边与窗口底边直角相接、四个角全是硬直角,观感生硬。
按用户反馈:**保持贴底的同时,把底部两个角改成圆角,并在圆角处留出部分空隙**
(圆角不再与窗口底角焊死,角上能看到透明的空隙)。

## 改动清单

### apps/pet(独立仓库)

| 文件 | 改动 |
|---|---|
| `src/renderer/index.html` | `#inputbar`:`bottom 0 → 6px`(底部抬高留空隙)、`border-radius 12px 12px 0 0 → 12px`(四角全圆角,底角不再直角)、`box-shadow 0 -2px → 0 2px`(恢复向下阴影,呼应"浮在底边上方"的观感);`#panel` 与 `#approval-card` 的 `bottom 54px → 60px` |
| `doc/changes/0024-inputbar-bottom-round-corners.md` | 本文 |

## 关键决策

1. **底部抬高 6px 而非保持 0**:若 `bottom: 0` 只加圆角,底角圆角曲线紧贴窗底边,
   圆角处的"空隙"只是角上一小块透明三角,几乎看不出;抬高 6px 后,底角圆角与窗口
   底角之间出现明确可见的透明空隙,符合"圆角处保留部分空隙"。两侧仍保持 `left/right: 0`
   通栏贴边(0023 已确认两侧贴边没问题,本次只动下方)。
2. **四角统一 12px 圆角**:顶部两角原本就是 12px,统一后视觉一致。
3. **阴影恢复向下(`0 2px 8px`)**:输入条现在悬浮于底边上方 6px,向下的阴影投在空隙里,
   强化"浮起"层次;0023 的向上阴影是为 `bottom: 0` 贴死时避免阴影被裁掉而设,已无必要。
4. **面板/审批卡 `bottom 54px → 60px`**:输入条整体上移 6px(顶边 42px → 48px),
   面板/审批卡同步上移 6px,保持与输入条之间原 12px 间距不变。

## 验证结果

- `apps/pet` grep `bottom: (54|64)px`:无残留(面板/审批卡已统一到 60px,输入条 6px)。
- `#inputbar` 现为 `left/right: 0; bottom: 6px; border-radius: 12px`:通栏贴两侧、
  底部 6px 空隙、四角圆角。
- 纯 CSS,renderer TS 无几何位置依赖(0023 已确认),typecheck 不受影响。
- 视觉确认:需重启 dev 窗口或重新构建后观察;若 6px 空隙偏大/偏小,调整 `bottom` 值即可。

## 遗留 / 后续

- 正在运行的宠物窗口需重启 dev / 重新构建后生效。
- 空隙大小(6px)是折中值:贴底感与圆角空隙的平衡点,如观感不佳可再微调。
