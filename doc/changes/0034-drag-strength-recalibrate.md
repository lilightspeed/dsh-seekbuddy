# 0034 · 拖动反馈强度重标定:0% = 当前效果,100% = 增益上限(接近编辑器满行程)

## 状态

## 日期

2026-08-18

## 目的

0033 的强度刻度(0 = 关闭,1 = 0032 原效果)下,设置 100% 时反馈仍远弱于 Live2D
编辑器 / 导出预览里的拖动效果 —— 根因是位移归一化太保守:当前实现把"窗口半宽/半高
(210px)"当作参数满行程,而人手拖动窗口 33ms 采样位移通常只有 5~60px,写入
`ParamDragX/Y` 的归一化值只有 0.02~0.3,远达不到参数 min/max,物理演算自然弱。
编辑器里拖动时参数可直接打满,故反馈强得多。

按用户要求重标定刻度:**0% = 当前反馈强度(起点),100% = 往后增加的强度参数(终点,增益上限)**。
默认 100% → 升级后默认即为增强效果,解决"默认太弱"。

## 关键决策

1. **0% = 0032 原效果**:gain = 1,`DRAG_FULL_TRAVEL` / `DRAG_SMOOTHING` 原样,
   保证"起点"就是用户已确认的效果,行为可预期。
2. **100% = 5× 增益**:窗口半宽 210px ÷ 5 = 42px —— 快速拖动(≥42px/采样,约
   1300px/s)即让参数饱和到 ±1(满行程),反馈强度与编辑器一致;中等拖动(20px)约 0.48,
   慢速(6px)约 0.14,各档位都有明显反馈。
3. **默认 1(100%)**:既有用户配置 `dragStrength=1` 升级后自动获得增强效果(语义变化,
   数值不变),不需要用户手动调;想回到原效果拉到 0%。
4. **线性插值**:0%..100% 均匀映射增益 1..5,滑块 21 档(step 5)粒度足够。
5. **增益作用在目标、再 clamp ±1**:参数值不可能超过程序满行程(映射到 min/max),
   饱和只发生在快速拖动段,慢速段仍随位移线性变化,不会"一碰就满"。
