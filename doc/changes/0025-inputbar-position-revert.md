# 0025 · 输入条位置回退 —— 整体贴底位置不动,仅保留底角圆角

## 状态

已验证(2026-08-17;纯 CSS 改动,静态验证,视觉效果待重启窗口确认)

## 日期

2026-08-17

## 目的

0024 在实现"底角圆角 + 圆角处留空隙"时,把输入条整体抬高了 6px(`bottom: 6px`)。
用户反馈:**输入框的整体位置不要改动** —— 输入条应保持 0023 的贴底位置
(`bottom: 0`,底边与窗口底边零空隙),圆角效果保留,圆角处的空隙由圆角本身自然形成。

## 改动清单

### apps/pet(独立仓库)

| 文件 | 改动 |
|---|---|
| `src/renderer/index.html` | `#inputbar`:`bottom 6px → 0`(位置回退贴底)、`box-shadow 0 2px → 0 -2px`(贴底时向下阴影会被窗底裁掉,恢复向上阴影);`border-radius: 12px` 保留(0024 的四角圆角不动);`#panel` / `#approval-card` 的 `bottom 60px → 54px`(随输入条顶边回落到 ~42px,保持 12px 间距) |
| `doc/changes/0025-inputbar-position-revert.md` | 本文 |

## 关键决策

1. **位置回退到 `bottom: 0`**:用户明确要求输入框整体位置不动;0024 的"底部抬高 6px 留空隙"
   方案移动了整体位置,违背需求,回退。
2. **圆角保留,空隙由圆角自身提供**:`border-radius: 12px` 四角圆角不变——输入条贴底后,
   底角圆角切掉的区域自然露出透明窗口背景,这就是"圆角处保留部分空隙"的效果,无需靠抬高
   位置来实现。
3. **阴影恢复向上(`0 -2px 8px`)**:贴底状态下,向下的阴影起点就在窗口底边,整体被窗口
   裁掉、不可见;向上阴影在 0023 贴底方案下验证过,恢复使用。
4. **面板/审批卡随动回退 `60px → 54px`**:输入条顶边从 48px 回落至 ~42px,面板/审批卡
   同步回退,维持与输入条之间 12px 的既有间距。

## 验证结果

- `#inputbar` 现为 `left/right: 0; bottom: 0; border-radius: 12px`:整体位置与 0023 一致
  (仅底角由直角变圆角),无抬高。
- `#panel` / `#approval-card` `bottom: 54px`,与 0023 一致。
- 纯 CSS,typecheck 不受影响。
- 视觉确认:需重启 dev 窗口或重新构建后观察。

  圆角半径或微调,但保持 `bottom: 0` 不动整体位置。
